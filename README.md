# 📓 To Do List

Una semplice applicazione web per gestire le proprie attività quotidiane, realizzata con **HTML, CSS e JavaScript**.

## ✒️​ Descrizione

Questo è un progetto personale per esercitarmi con le basi di sviluppo front-end: gestione degli eventi e logica applicativa in JavaScript.

## ​❓​ Funzionalità

-  Aggiungere nuove attività alla lista
-  Segnare le attività come completate
-  Eliminare le attività non più necessarie
-  Salvataggio delle attività così la lista non si perde ricaricando la pagina

## 🛠️ Tecnologie utilizzate

- **HTML5** — struttura della pagina
- **CSS3** — stile e layout
- **JavaScript** — logica dell'applicazione 

## 🚀 Come usarla

Clicca qui accanto l'URL <a href="https://github.com/Gallogc/ToDoList">To Do List</a> e inizia subito ad aggiungere la tua attività

## 🎯 Obiettivo del progetto

Questo progetto fa parte del mio percorso di apprendimento nello sviluppo web front-end, per mettere in pratica in autonomia i concetti fondamentali di HTML, CSS e JavaScript.
